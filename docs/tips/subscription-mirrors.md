# Subscription mirrors (CN / IR)

When `github.com` or `raw.githubusercontent.com` is blocked:

1. Prefer **Subscription via proxy** while Connected (Settings).
2. v2rayF automatically retries common public GitHub reverse proxies (`ghproxy.net`, `mirror.ghproxy.com`, `gh.ddlc.top`).
3. Or paste a working mirror URL / import a local file (File button).
4. Do not commit live subscription tokens to the repo.

In-app Update still uses GitHub releases; sideload a mirrored APK if Update check cannot reach GitHub.
