# Private DNS + battery (fa / zh)

## English

- **Private DNS:** Off (Settings → Network → Private DNS). Opportunistic/strict breaks VPN DNS.
- **Battery:** Allow unrestricted / ignore battery optimizations for v2rayF so the tunnel is not killed.
- **Free servers:** See [pulse-free-servers.md](./pulse-free-servers.md) for PulseConfigs Free button, TLS fragment, and DoH tips on hard-filter days.

## فارسی (fa)

- **DNS خصوصی:** خاموش — تنظیمات → شبکه → Private DNS / DNS خصوصی باید Off باشد وگرنه VPN درست کار نمی‌کند.
- **باتری:** برای v2rayF بهینه‌سازی باتری را غیرفعال کنید (بدون محدودیت) تا اتصال قطع نشود.
- **سرور رایگان:** راهنمای دکمه Free (Pulse) و روزهای فیلترینگ شدید در [pulse-free-servers.md](./pulse-free-servers.md).

## 中文 (zh)

- **私人 DNS：** 关闭（设置 → 网络 → 私人 DNS）。否则 VPN 劫持 DNS 会失败。
- **电池优化：** 对 v2rayF 关闭电池优化 / 允许后台运行，否则隧道易被系统杀掉。
- **免费节点：** Free (Pulse) 与严审查日提示见 [pulse-free-servers.md](./pulse-free-servers.md)。
