# v2rayF v1.4.9

More reliable connect and latency testing: real proxy-path health checks, fixed domain-node DNS bootstrap, and fuller Windows system proxy.

## Highlights

- **Connected means traffic works** — post-connect HTTPS probe through SOCKS before the UI shows Connected
- **Domain nodes** resolve via direct public DNS (no DoH-through-proxy chicken-and-egg)
- **Windows** system proxy sets `http` + `https` + `socks` with LAN overrides
- **Smart Connect** keeps Adaptive Survive in play when all delay probes time out; Reality/domain shortlist hardened
- Latency tests use ephemeral ports and optional fragment; sniffing on local SOCKS/HTTP
