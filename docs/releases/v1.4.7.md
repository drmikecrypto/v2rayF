# v2rayF v1.4.7

Bulk import UX, Google Code Scanner QR, and more reliable delay tests.

## Highlights

- **Add stays on screen** when pasting long multi-link configs (capped paste box + fixed Paste/Add/QR row on mobile)
- **QR** opens Google Code Scanner (system QR UI) on Android; image pick remains the fallback
- Bulk paste / `.txt` / QR still import **one server per share link** (Reality, Vision, WS, gRPC, HTTPUpgrade, Trojan, VMess, SS)
- Delay tests resolve domain nodes via public DNS and probe Cloudflare → gstatic → Google (fewer false timeouts)
