# v2rayF v2.2.6

Fix sing-box Android TUN config rejection.

## Fixed

- Removed invalid **`file_descriptor`** from sing-box JSON (sing-box 1.12 rejects it — caused `unknown field "file_descriptor"`)
- Android VPN TUN fd is passed via **`SING_BOX_TUN_FD=3`** to a **patched libsingbox.so** (release builds compile this in CI)
- TUN inbound uses **`address`** instead of deprecated `inet4_address`

## Install

Tap **Update** in the app when offered. This release replaces **libsingbox.so** — in-app Update is enough.
