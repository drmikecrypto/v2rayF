# v2rayF v2.0.8

Max Connected throughput across platforms: empty desktop TUN sniff, no silent Survive fragment, higher Android MTU.

## Highlights

- **Desktop TUN:** empty sniff `destOverride` (match Android) — WS/Trojan/SS no longer fight TLS sniff
- **Smart Connect:** never auto-enables Packet fragment / Survive unless Adaptive Survive is on
- **Android MTU 1400** (was 1280)
- **Windows** system proxy: HTTP+HTTPS only
- Connected UI: `TCP · path HTTPS` so green delay is not mistaken for Mbps

Leave Packet fragment and Adaptive Survive off for max speed. Uninstall old Android APK before install.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
