# v2rayF v1.4.4

Windows in-app update button parity with Android.

## Highlights

- Desktop always shows **Check for updates**; switches to **Update x.y.z** when GitHub has a newer release
- Rechecks on window focus (throttled); status explains latest / check failures
- Safer Windows apply script (writable install folder check, escaped paths)
- More reliable version compare (`1.4.3` vs `1.4.3.0`)

## Platform packages

| File | Platform |
|------|----------|
| `v2rayF-win-x64.zip` | Windows x64 |
| `v2rayF-win-arm64.zip` | Windows ARM64 |
| `v2rayF-linux-x64.zip` | Linux x64 |
| `v2rayF-linux-arm64.zip` | Linux ARM64 |
| `v2rayF-osx-x64.zip` | macOS Intel |
| `v2rayF-osx-arm64.zip` | macOS Apple Silicon |
| `v2rayF-android-arm64.zip` | Android ARM64 APK |
| `SHA256SUMS` | Checksums for all zips |

Keep the app in a user-writable folder (not `Program Files`) so Update can replace files and restart.
