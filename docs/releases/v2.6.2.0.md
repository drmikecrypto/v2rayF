# v2rayF v2.6.2.0

Push notifications and per-app session survival on Android and desktop TUN.

## Fixed

- **No notifications while connected** — WhatsApp, Telegram, Discord, and FCM push hosts use real DNS + explicit proxy routes (not FakeIP + sniff alone)
- **Kill app → reopen → no internet** until Disconnect/Connect — Android network callback + TUN app-path probe detect stale FakeIP and auto-recover
- **Desktop messenger toasts** — Telegram/Discord push suffixes routed via proxy alongside WNS when TUN is on

## Added

- TUN health probe uses default-route `generate_204` + `mtalk.google.com` (localhost SOCKS can look fine while apps are dead)
- Soft runtime refresh — restart sing-box without tearing down VPN fd
- Periodic `ReportVpnReady` every 90s after successful path health (Android captive-portal validation)
- Settings label: *Route push notifications (WNS, Telegram, Discord) via proxy*

## Verify

**Android (leave v2rayF in background):**

1. Connect → send WhatsApp/Telegram/Discord messages → notifications arrive
2. Force-stop one app → reopen → works without opening v2rayF or tapping Disconnect
3. Instagram Direct + Play Store still work

**Desktop TUN:**

1. Telegram/Discord desktop notifications while connected
2. Lock/sleep/wake — apps recover without manual reconnect
