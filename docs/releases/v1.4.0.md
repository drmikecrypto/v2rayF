# v2rayF v1.4.0

Hardening, connect agility, and broad share-link / stream support across every platform we ship.

## Highlights

- Secrets encrypted at rest (DPAPI / Keystore / restricted key file)
- `.v2rayf` passphrase vault export & import
- Adaptive Survive after Smart Connect failures (top candidates only)
- Faster Smart Connect (early-exit, probe budget, first-success generate_204)
- Config matrix: Vision+REALITY, Vision+TLS, Trojan REALITY/WS, TCP/WS/gRPC/H2/HTTPUpgrade/xHTTP/mKCP/QUIC
- Updater: GitHub host allowlist, SHA256 verification, Zip-Slip-safe extract; `SHA256SUMS` on the release
- Secure Share binds LAN IP by default; password reveal/copy behind vault unlock
- Android backup disabled (`allowBackup=false`)
- Core unit tests in CI
