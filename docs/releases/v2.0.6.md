# v2rayF v2.0.6

Idle keepalive + per-transport Android TUN so zombie tunnels reconnect and phone apps work on WS/TCP/SS/Trojan/HTTPUpgrade.

## Highlights

- **TCP keepalive** on every long-lived outbound (`idle 45` / `interval 15`); Vision keeps splice-safe keepalive without `tcpNoDelay`
- **Soft path health**: every 60s when traffic is flat, one SOCKS `generate_204`; 2 fails → AutoReconnect (up to 2 attempts)
- **Android TUN**: empty sniff `destOverride` for all Xray transports (not Vision-only)
- Fragment sockopt **merges** `dialerProxy` with keepalive

Uninstall the old APK before installing this one if you are on Android.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
