# v2rayF v2.0.7

Non-REALITY Connect throughput: stop stacking VPN HTTP CONNECT on WS/TLS; default xudp for VLESS/VMess.

## Highlights

- **Android:** no more `SetHttpProxy(127.0.0.1:10809)` — Chromium uses TUN like other apps (empty sniff from 2.0.6)
- **VLESS/VMess:** default `packetEncoding=xudp` when the link omits it
- Tip: green delay is not Mbps; leave Packet fragment / Adaptive Survive off unless DPI blocks Connect

Uninstall the old APK before installing this one. Private DNS Off. Fragment Off.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
