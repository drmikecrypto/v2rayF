# v2rayF v2.2.10

Fix Instagram Direct and Telegram on Android (TUN UDP DNS).

## Fixed

- Feed/reels could work via HTTP proxy `10809` while **Direct** and **Telegram** stayed offline
- Android TUN uses **`mixed`** stack (system TCP + gVisor UDP) so VpnService DNS to `172.19.0.1:53` is answered
- Live Connect forces **UDP DNS** for hijacked app queries (DoH remains for non-TUN)

## Install

Tap **Update** in the app when offered. Private DNS Off → Connect → **force-stop Instagram and Telegram once**.
