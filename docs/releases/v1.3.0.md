# v2rayF v1.3.0

**Sentinel** release — anti-censorship hardening with Smart Connect, leak shield, multipath, and Secure Share.

> **iOS:** not included. This release covers Windows, Linux, and Android (plus optional macOS desktop zips from CI if built separately).

---

## Highlights

- **Smart Connect** — pick the fastest *working* node (proxy-path probe + failover)
- **Smart Multipath** — balance across top servers via Xray observatory
- **Leak shield** — DNS through proxy, IPv6 block, fail-closed kill switch (Windows Firewall + Android VPN)
- **Secure Share** — authenticated LAN SOCKS/HTTP so phone↔PC / hotspot clients use the tunnel
- **Routing** — Global/Sentinel, Bypass LAN, Bypass China, Custom Direct/Proxy/Block
- Reliable connect/disconnect with crash-aware teardown

## Install notes

- **Windows:** extract → run `v2rayF.exe`. TUN / kill switch need **Administrator**.
- **Linux:** `chmod +x run-v2rayF.sh && ./run-v2rayF.sh`
- **Android:** install `v2rayF-android-arm64.apk` from the zip; grant VPN permission on connect.
