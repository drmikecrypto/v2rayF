# v2rayF v2.2.8

Fix sing-box 1.12 DNS on Android Connect.

## Fixed

- Live sing-box config uses **1.12 DNS format** (`type: udp/https` + `server`) instead of deprecated legacy `address` fields
- Domain-named nodes get bootstrap DNS **rules** and proxy outbound **`domain_resolver`**
- Connect errors show **FATAL/ERROR** lines instead of cut-off migration URL text

## Install

Tap **Update** in the app when offered (from v2.2.7). Private DNS Off → Connect.
