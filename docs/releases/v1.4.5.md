# v2rayF v1.4.5

Scrollable configs, Google latency, hidden updates, and live traffic meters.

## Highlights

- Phone server list scrolls inside a fixed viewport (large subscriptions)
- Desktop list virtualization for many servers
- Latency tests probe **www.google.com** through each proxy
- **Update** button stays hidden until a newer GitHub release (with SHA256) is published
- Connected sessions show accurate ↑/↓ totals from Xray Stats (UI + Android notification)
