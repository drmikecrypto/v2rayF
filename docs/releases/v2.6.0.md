# v2rayF v2.6.0

Startup ranking, stable long sessions, Windows notifications, deeper Instagram Direct.

## Added

- **Rank on startup** — ping all servers in background, fastest on top + auto-selected (manual override sticks)
- **Long-session stability** — NAT keepalive every 25s; path health 60s / 3 fails before reconnect
- **Windows toasts** — WNS domains routed via proxy under TUN (Telegram/Discord/Phone Link)
- **Instagram Direct** — more MQTT hosts + sing-box explicit proxy route rules

## Settings

- *Rank servers on startup* (Connect section, default on)
- *Route Windows notifications via proxy* (desktop TUN, default on)

## Install

Update → open app (servers reorder) → Connect. Android: Private DNS Off → force-stop Instagram once for Direct.

See [tip-desktop-connect.md](../tip-desktop-connect.md) and [tip-android-connect.md](../tip-android-connect.md).
