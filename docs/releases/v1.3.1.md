# v2rayF v1.3.1

Patch release — fixes Android Connect crashing when UI updates resumed off the Avalonia thread.

> **iOS:** not included. This release covers Windows, Linux, Android, and macOS (CI desktop/Android packages).

---

## Highlights

- **Android Connect fix** — status/busy/connected property updates are marshalled to the Avalonia UI thread after VPN permission and Xray start (no more “different thread owns it” / activity kill on Connect)
- Android display version and version code aligned with **1.3.1** (code `13`)

## Install notes

- **Windows:** extract → run `v2rayF.exe`. TUN / kill switch need **Administrator**.
- **Linux:** `chmod +x run-v2rayF.sh && ./run-v2rayF.sh`
- **Android:** install `v2rayF-android-arm64.apk` from the zip; grant VPN permission on connect. Upgrade over previous APK needs the higher version code (this build: `13`).
