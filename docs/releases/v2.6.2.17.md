# v2.6.2.17

## Why

Test All marked every Sentinel link TIMEOUT (Reality, WS, gRPC, Trojan, VMess, SS, plain TCP) while the same links worked in other clients.

1. **v2.6.2.14 D13** — Android Test All uses sing-box. `BuildSpeedtest` reused live `Build()`, which emits `ip_is_private → direct`. That rule resolves the destination domain locally. Probe URLs are hostnames, so every SOCKS CONNECT waited on DNS.
2. **v2.6.2.16** — SOCKS probes send DOMAIN ATYP (correct for poisoned ISP DNS), but speedtest DNS was still **clearnet UDP 1.1.1.1** with no `detour: proxy`. Blocked/slow 1.1.1.1 → every protocol TIMEOUT.
3. Non-Vision rank was hard-capped at **4s** (outbound `connect_timeout` is 10s).

## Fixes

- Lean sing-box speedtest: mixed SOCKS only (no 10809/TUN), `route.final = proxy`, no `ip_is_private`
- Dest DNS `detour: proxy`; outbound hostname still uses clearnet bootstrap
- Rank / Test All budget **12s for all** protocols
- Probe HTTP/1.1; Vision/REALITY rank uses a single Cloudflare gen204 URL

Live Connect TUN routing is unchanged.
