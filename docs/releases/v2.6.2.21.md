# v2.6.2.21

## Why

2.6.2.20 defaulted **Chromium HTTP proxy assist** off (no `SetHttpProxy(10809)`, no Google UDP/443 block). That recreated the known **2.3.1** Play Store / Translate failure. v2.6.2.19 had always used the Chromium CONNECT path.

Narco Empire / V2Box parity is **not** solved by assist-off alone: live TUN remains `stack: gvisor` (system/`mixed` blackholed VpnService in 2.4.1). Assist off made Narco diagnosis worse while breaking Google.

## Fixes

- `ChromiumHttpProxyAssist` **default true**
- Settings storage v3 migration: force assist **on** once when upgrading from ≤v2 storage (recovers v20 users who saved false)
- Iran / China / Sentinel profiles set assist on
- Toggle kept; tip warns that assist off breaks Play

Preserved from 2.6.2.20: no Instagram Connected tip, no path-truth line, Paste native clipboard fallback.
