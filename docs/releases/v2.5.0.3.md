# v2rayF v2.5.0.3

Instagram Direct while keeping feed online.

## Fixed

- Direct MQTT was trapped in VPN HTTP CONNECT (`10809`) after 2.5.0.2 emptied Meta exclusions
- Now only realtime hosts bypass the proxy (`edge-mqtt`, `mqtt-mini`, `gateway.instagram.com`, `graph.instagram.com`, …) → TUN + real DNS
- Feed/CDN remain on `10809` (no full `*.instagram.com` exclusion)

## Install

Tap **Update**. Private DNS Off → Connect → force-stop Instagram once → test Direct. Confirm feed still loads.
