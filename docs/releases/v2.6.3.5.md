# v2.6.3.5

## Why

Windows TUN could stay **Connected** with localhost SOCKS green while the `v2rayF` WinTun adapter was gone — kill switch still armed → device blackhole. Android already fail-closed on missing VpnService Network (`TunVpnMissingMs`); desktop only returned advisory HTTPS miss (`-1`).

## Fixes

- Desktop `ProbeTunAppPathAsync`: missing `v2rayF` adapter → `TunVpnMissingMs` (same Connect fail-closed gate as Android).
- Kill switch waits on `DesktopTunInterface` (no PowerShell adapter race).
- Soft recovery / session resume escalate when WinTun stays missing after `RefreshRuntime`.
- Golden-matrix soak runbook + scorecard rows for lock/unlock and Windows TUN honesty.
