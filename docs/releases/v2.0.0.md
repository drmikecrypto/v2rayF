# v2rayF v2.0.0

Dual-core: Xray for classic stacks, sing-box for Hysteria2 / TUIC / WireGuard / anytls.

## Highlights

- **sing-box** bundled on desktop next to Xray
- Import + Test + Connect for hy2 / TUIC / WG / anytls
- Clash Meta and sing-box JSON import those types too
- Xray path unchanged for Vision / REALITY / VMess / Trojan / SS

See [supported-configs.md](../supported-configs.md) and [CHANGELOG.md](../CHANGELOG.md).
