# v2.6.3.6

## Why

Gaming mode only flipped Chromium HTTP assist off. That is necessary for Unity/UDP but not a booster. Users (and GearUP comparisons) expect UDP-aware path selection, multipath that reacts mid-match, and no fragment/Survive latency poison — without pretending we own a private AIR backbone.

## Added

- **Gaming Boost** preset: full TUN; assist / fragment / Survive off; Smart Multipath + Smart Connect on; `GamingBoostActive` persisted.
- UDP-aware Smart Connect (`RankProfile.Gaming`): prefer Hy2/TUIC/WG; penalize Vision/REALITY when a nearby UDP peer works.
- Xray `burstObservatory` interval **15s** when Gaming + multipath (else 1m).
- Tighter path-health cadence while Gaming Boost is Connected.
- Bundled `game-catalog.json` + Settings **Apply game catalog → App Network Direct** (optional; default stays full tunnel).
- Tip: `docs/tips/gaming-boost.md`.
