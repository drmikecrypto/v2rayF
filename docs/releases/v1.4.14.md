# v2rayF v1.4.14

Stop the post-connect speed cliff: no more false Survive→fragment sessions, and the ping label no longer jumps from ~100ms TCP to ~1500ms cold HTTPS.

## Highlights

- **Connect health** — warmup GET + timed GET; 8s normal / 12s Vision·REALITY (fewer false fails into Adaptive Survive)
- **Ping label** — keeps Test All TCP ms after Connect; never overwrites the list with the HTTPS probe
- **Adaptive Survive** — **off by default** (opt-in; fragment stays slow when you enable it)
