# v2rayF v2.4.0

App Network — lightweight per-app VPN / Direct / Block control.

## Added

- **App Network** manager (Settings → Open App Network)
- **VPN** (default), **Direct** (split), **Block** (deny while connected)
- Android app picker + optional live rates while the panel is open
- Desktop process list when using TUN (Direct = core direct, not OS bypass)

## Notes

- No background per-app traffic polling (battery-friendly)
- Changing modes while connected reconnects once to apply
- Legacy per-app bypass package lists migrate to **Direct**

## Install

Tap **Update**, then Settings → **Open App Network**.
