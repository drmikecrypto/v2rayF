# v2rayF v2.2.5

Android Connect ready timeout after in-app Update.

## Fixed

- Connect no longer fails at ~4s with **“Xray core did not become ready in time”** when sing-box + VPN TUN needs longer to bind **10808**
- Ready wait uses the full **15s** Connect budget plus sing-box/TUN bonus; errors name the correct core and show stderr when available
- sing-box live route disables **auto_detect_interface** on Android VPN (faster, more reliable startup)

## Install

Tap **Update** in the app when offered, or install `v2rayF-android-arm64.apk` from this release over the existing app. Private DNS Off → Connect.
