# v2.6.4.0

## Why

Free used to dump the published top5 into the list. That ignored *your* path: a node that is “good” in the pack can be 500ms+ (or dead) on IR/CN ISP routes, and re-taps could churn user-looking entries.

## Changed

- **Free** keeps at most **5** servers tagged `Source=pulse-free`.
- On-device probe: TCP then proxy path; keep only **1–150ms**.
- Re-tap: keep Fast Free; replace slow/failed Free only; never touch user imports.
- Prefer `candidates.json` shortlist; soft `POST /refresh` when Worker base is known.
- 60s cooldown; green **Free** badge in the list.
- Optional `PulseWorkerBase` in settings (no UI field).

## Verify

```powershell
dotnet test src/v2rayF.Core.Tests/v2rayF.Core.Tests.csproj -c Release
```

Tap **Free** twice: first fill ≤5 under 150ms; second should keep good Free and only swap slow ones. Imported servers must stay.
