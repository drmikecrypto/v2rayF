# v2.6.3.1

## Why

Ping / Test All and Connect could look green while **system apps had no internet**. Connect gated on localhost SOCKS (app is VPN-disallowed); VpnService still held `0.0.0.0/0`. A dead TUN then blackholed the device. Connect was also slow because HTTP 10809 and HTTP port ready waited on the critical path.

## Fixes

- Fail-closed after SOCKS if TUN app-path still fails: Android **rebinds VPN once**, then tears down with `TUN path failed — system traffic has no internet` (never silent Connected blackhole).
- Desktop TUN + kill switch: same tear-down on TUN path failure.
- `VerifyLivePath` requires TUN OK when TUN is active.
- Faster Connect: skip advisory HTTP probe on Connect gate; ready = SOCKS port accept.
- Vision/REALITY TUN probe budget 12s after SOCKS warmup.
