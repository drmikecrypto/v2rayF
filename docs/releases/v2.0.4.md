# v2rayF v2.0.4

Android Vision: Connected now means apps get internet, not only the SOCKS probe.

## Highlights

- **Vision on phones** — TUN no longer sniffs TLS/HTTP into the Vision splice (gVisor)
- IPv6 blackhole applies to **TUN only** (SOCKS/HTTP proxy path stays usable)
- Non-Vision Android still sniffs `http,tls` for Chrome/Play (v2.0.3)

Uninstall the old APK, then install this one. Set Android **Private DNS** to Off if browsers still fail.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
