# v2.6.3.3

## Why

Instagram Direct could **send and like** while **pull-to-refresh / other posts** stalled. Daily assist splits traffic: MQTT/graph bypass `SetHttpProxy` onto TUN (chat works); feed/CDN stay on `10809` and may hang on Meta HTTP/3 over gVisor (Google already had UDP/443 shove; Meta did not). Connect also skipped HTTP probes, so weak `10809` was silent.

## Fixes

- Assist on: Meta feed/CDN UDP/443 block (`instagram.com`, `cdninstagram.com`, `fbcdn.net`) — not `facebook.com`.
- MQTT HTTP exclusions unchanged (Direct stays on TUN).
- Async post-connect `10809` advisory + tip mentions Instagram feed/CDN.
- One-shot force-stop Instagram tip after Connect / TUN rebind.
