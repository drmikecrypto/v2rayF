# v2rayF v2.6.2

Steady VPN sessions after idle, lock, and wake.

## Fixed

- **Connected but no internet** until manual Disconnect — wake/resume now verifies the live path and silently reconnects if needed
- Zombie tunnels while apps still show traffic — path health runs every **90s** even when not idle
- Android Chromium apps (Play Store, Chrome) — health uses SOCKS **+ HTTP 10809**, same as Connect
- Kill switch trapping users after failed auto-reconnect — clearnet restored; tap **Connect** to get VPN back

## Behavior

- Lock phone / sleep PC → wake → path checked within 30s throttle
- Idle path probes every **45s** (was 60s); **3** fails still before drop
- Auto-reconnect up to **3** attempts; then clearnet + *VPN offline — tap Connect to restore protection*
