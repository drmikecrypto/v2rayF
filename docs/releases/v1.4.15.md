# v2rayF v1.4.15

Stable live connection: less mid-session stutter, fewer false disconnects, kill switch only with TUN.

## Highlights

- **Traffic stats** — 5s single-flight poll (no stacked `xray api` spawns)
- **HealthLoop** — 3 consecutive SOCKS misses before drop; no Idle/`Disconnected` flash
- **Kill switch** — only with TUN (system proxy no longer blackholes apps)
- **Defaults** — Secure DNS (DoH) and Adaptive Survive off
