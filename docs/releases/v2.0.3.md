# v2rayF v2.0.3

Android TUN: Chrome / Play Store / Translate work the same path as Instagram.

## Highlights

- **Block IPv6** now blackholes `::/0` in Xray (VpnService already captured it)
- Android VPN HTTP proxy `127.0.0.1:10809` so Chromium matches desktop CONNECT
- MTU 1280, DNS 1.1.1.1 / 8.8.8.8, re-validate VPN after Xray starts
- TUN sniff HTTP/TLS only (no QUIC rewrite)

If browsers still fail: set Android **Private DNS** to Off, uninstall the old APK, install this one.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
