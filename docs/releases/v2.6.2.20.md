# v2.6.2.20

## Why

Same Sentinel links in **V2Box**: Narco Empire network diagnosis clean and play smooth. In v2rayF: DNS/TCP Normal but Latency / Route / **Web Access** Issue and lag. Root delta: Android always called `VpnService.SetHttpProxy(127.0.0.1:10809)`, so Unity/`HttpURLConnection` used HTTP CONNECT while raw TCP ping stayed fine.

Also: connected UI showed Instagram force-stop tip + verbose path-truth; Android **Paste** often failed while **Add** worked (Avalonia clipboard empty on single-view).

## Fixes

- **Chromium HTTP proxy assist** Settings toggle — **default off** (V2Box-shaped full TUN)
- When off: no `SetHttpProxy`; omit Google UDP/443 Chromium shove
- When on: previous behavior (10809 + Meta MQTT exclusions + Google UDP/443 block) for Play/Translate
- Connected status: no Instagram tip; path-truth line removed
- Paste: Avalonia clipboard first, then Android `ClipboardManager` fallback

Latency / Route Analysis may still flag ICMP under any VLESS VPN (ICMP does not ride proxy outbounds). Do not treat ICMP-only reds as a tunnel failure if Web Access and play match V2Box.
