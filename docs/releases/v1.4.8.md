# v2rayF v1.4.8

QR import removed; Android Play-hardened permissions and browser-only updates.

## Highlights

- **QR removed** — import via paste, clipboard, subscription URL, or config file only
- **Android** drops `CAMERA`, Google Code Scanner / ML Kit, and `REQUEST_INSTALL_PACKAGES`
- **Update** on Android opens the GitHub Releases page in the browser (manual APK install)
- VPN/TUN and leak-shield behavior unchanged
