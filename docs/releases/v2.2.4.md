# v2rayF v2.2.4

Android Connect finds sing-box after in-app Update.

## Fixed

- Packaged **libsingbox.so** in the Android APK (same NativeLibs path as libxray.so)
- Connect no longer fails with “sing-box core not found” on classic Android configs
- Use the in-app **Update** button when it appears — that installs the new APK on top and refreshes cores. Uninstall is only needed for ancient signature-mismatch upgrades

## Install

Tap **Update** in the app when offered, or install `v2rayF-android-arm64.apk` from this release over the existing app. Private DNS Off → Connect.
