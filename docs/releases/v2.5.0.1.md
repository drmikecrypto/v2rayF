# v2rayF v2.5.0.1

Hotfix for 2.5.0 Connect hang + remove Instagram clearnet Settings toggle.

## Fixed

- Bootstrap DNS no longer uses `detour: proxy` (that deadlocked hostname nodes with `domain_resolver` → “sing-box did not become ready in time”)
- App TUN UDP DNS still resolves via proxy after the tunnel is up
- Removed `tcp_keep_alive` (1.13-only on bundled 1.12)

## Removed

- **Split Instagram for Direct** Settings checkbox — Instagram stays on VPN; use **App Network** for intentional Direct splits

## Install

Tap **Update**. Private DNS Off → Connect → force-stop Instagram once → test Direct and other apps on the VPN.
