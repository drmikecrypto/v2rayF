# v2rayF v2.2.0

Beat V2Box engine foundation: default DoH Connect, Android classic protocols on sing-box TUN.

## Highlights

- **Secure DNS ON by default** — no more “turn on Secure DNS or Connect fails”
- Softer connect gate (12s / 16s Vision) + one automatic DoH retry
- **Android:** VLESS/VMess/Trojan/SS/REALITY/Vision use **sing-box** + TUN fd (same VpnService path as Hy2)
- Chromium HTTP proxy kept until QA proves TUN-only is enough
- Phase C UI / SpeedyFi aggregation deferred — see [roadmap-engine-first.md](../roadmap-engine-first.md)

Uninstall old APK → install 2.2.0 → Private DNS Off → Packet fragment Off.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
