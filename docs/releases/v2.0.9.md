# v2rayF v2.0.9

Emergency Connected speed restore after 2.0.7/2.0.8 regressions.

## Highlights

- Restore Android **VPN HTTP proxy** `127.0.0.1:10809` (Chromium CONNECT)
- Android MTU **1280** again
- `packetEncoding` only when the share link sets it (no forced xudp)
- Desktop TUN sniff: `http,tls` (Android empty sniff kept)
- Windows system proxy: HTTP+HTTPS+SOCKS again

Uninstall the old APK, install this one, Private DNS Off, Packet fragment Off.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
