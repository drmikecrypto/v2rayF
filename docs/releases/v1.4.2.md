# v2rayF v1.4.2

Connect reliability fix for Windows TUN and Android VPN.

## Highlights

- Windows packages include `wintun.dll` next to `xray.exe` (required for TUN)
- Xray startup failures show the real core message (WinTun missing, Access denied, port 10808/10809 in use) instead of “exited immediately”
- Android VpnService binder + tunnel exclusions + gVisor TUN fd stack; startup exit no longer races Connect teardown
- Docs: WinTun / port-conflict / Android reinstall notes

**Android:** uninstall the previous APK once before installing 1.4.2 if upgrading from a debug/unsigned build, then use a Compat VLESS link (avoid Vision flow on phones).
