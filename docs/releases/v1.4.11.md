# v2rayF v1.4.11

Per-transport Test + Connect parity for multi-protocol subscriptions (deep_fix matrix).

## Highlights

- **Test == Connect outbound** — speedtest uses `BuildServerRuntime` with the same DNS bootstrap and stream settings as live connect
- **Smart Connect fairness** — transport-diverse shortlist (WS, gRPC, Trojan, VMess, SS, plain TCP); your selected row is probed first; up to 10 proxy probes on large lists
- **Mobile UI** — each server row shows `VLESS · ws · tls` style transport label
- **Probe timing** — longer SOCKS bind wait for WS/gRPC/HTTPUpgrade handshakes
