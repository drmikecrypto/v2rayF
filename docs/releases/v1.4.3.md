# v2rayF v1.4.3

Android Connect crash fix and Windows Global+TUN routing fix.

## Highlights

- **Windows:** Xray-core **v26.7.28** with real TUN schema (`gateway` / `autoSystemRoutingTable` / `dns` / `autoOutboundsInterface`) so Global + TUN + kill switch can reach the internet
- **Android:** VpnService FGS-safe start/stop; Xray started via `posix_spawn` so the VPN TUN fd is inherited; clearer TUN fd errors
- UI: removed the “Anti-censorship proxy hub…” / “Android Sentinel — …” marketing subtitles

**Android:** uninstall the previous APK once before installing 1.4.3, then use a Compat VLESS link (avoid Vision flow on phones).

**Windows TUN:** run as Administrator when using TUN + kill switch.
