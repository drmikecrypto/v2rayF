# v2rayF v1.4.10

Fixes all-config latency timeouts (broken SOCKS probe scheme) and restores Android in-app updates.

## Highlights

- **Timeouts fixed** — probes use `socks5://` (`.NET` rejects `socks5h://`, which made every Test/Connect health check fail while Xray itself was fine)
- **Android Update** downloads + installs the APK on top of the current install again (allow “Install unknown apps” for v2rayF when prompted)
- Desktop Update still replaces files in-app and restarts
