# v2rayF v1.3.2

Patch release — fixes Android in-app Update so installs actually upgrade the app.

> **iOS:** not included.

---

## Highlights

- **Stable Android signing** — every GitHub Release APK is signed with the same release keystore (no more one-off CI debug keys)
- **Update button** — clearer install prompts/failures; re-checks version when you return to the app
- **versionCode 10302** — package version code now follows SemVer so Android always sees a real upgrade

---

## Important for existing Android installs

If you installed **1.3.1 or earlier** from GitHub Releases, that APK was signed with an ephemeral debug key. Android will **not** allow an in-app upgrade onto a differently signed package.

1. Uninstall the current v2rayF app (settings/servers in app storage are removed).
2. Install `v2rayF-android-arm64.apk` from this release.
3. Later Updates can stay in-app.

## Install notes

- **Windows:** extract → run `v2rayF.exe`. TUN / kill switch need **Administrator**.
- **Linux:** `chmod +x run-v2rayF.sh && ./run-v2rayF.sh`
- **Android:** install `v2rayF-android-arm64.apk` from the zip; grant VPN permission on connect.
