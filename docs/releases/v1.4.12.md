# v2rayF v1.4.12

Latency numbers now match v2rayN’s ~100ms TCP ping, without treating a dead tunnel as success.

## Highlights

- **List delay is TCP RTT** (v2rayN tcping) after an HTTPS-through-Xray check succeeds
- **timeout** still means the proxy path failed — TCP-only is never shown as a ping
- Probes **warmup** then time two sequential Cloudflare `generate_204` requests (no 4-URL cold race)
- Connect health uses the same fast probe (~4s), so Connected is not blocked on a 10s handshake
