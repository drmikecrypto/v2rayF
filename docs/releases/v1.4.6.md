# v2rayF v1.4.6

Honest delay tests, multi-format import, live speed meters, and sticky selection.

## Highlights

- **Test delay** shows real proxy-path RTT to Google — dead nodes report `timeout`, not TCP-only ms
- Import files (`.txt` / `.json` / `.v2box` / `.npv`), Xray JSON from clipboard, and QR (camera or image), including bulk lists
- Connected ↑/↓ show live **rates**; ping number sits beside traffic (UI + notification)
- Selected server is remembered across restarts; import no longer jumps to the first config
- Closing the Android app clears the VPN notification; Smart Connect defaults on for fastest working path
- Lighter background stats polling (shared hub, fewer `xray api` process spawns)
