# v2rayF v2.5.0

Instagram Direct (safe path) + faster/stabler Connect. Does **not** restore TUN `mixed` (that blackholed traffic in 2.4.1).

## Direct

- TUN UDP DNS / bootstrap: resolve through **`detour: proxy`**
- More Meta MQTT hosts + `threads.net`
- Outbound dial keep-alive / connect timeout; TUN `udp_timeout` 5m
- After Connect: force-stop Instagram once
- Optional **Split Instagram for Direct** (clearnet) — off by default; only if still dark

## Connect quality (all configs)

- Parallel SOCKS `10808` + HTTP `10809` probes; lighter HTTP probe
- Path health at 45s when traffic is flat

## Install

Tap **Update**. Helper toggle **off** first → Private DNS Off → Connect → force-stop Instagram → test Direct. Confirm Play Store / Translate / WhatsApp / YouTube. If Direct still dead, enable the split helper and reconnect.
