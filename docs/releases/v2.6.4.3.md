# v2.6.4.3

## Why

Secure Share was Xray-only and used a naive LAN IP (often wrong for Mobile Hotspot). Android classic Connect (sing-box) could not share the tunnel to other devices.

## Added / Changed

- sing-box authenticated SOCKS/HTTP share inbounds (same ports as Xray)
- SoftAP / Mobile Hotspot–aware advertise IP ranking
- Windows temporary inbound firewall rules for share ports
- Settings: Secure Share for both cores; Copy SOCKS / HTTP / setup tip
- Tip rewrite: [`docs/tips/secure-share.md`](../tips/secure-share.md)

## Not in this release

Transparent ICS / zero-config hotspot NAT (clients still set a proxy once).

## Verify

```powershell
dotnet test src/v2rayF.Core.Tests/v2rayF.Core.Tests.csproj -c Release --filter FullyQualifiedName~SecureShare
```

Host: Connect → Secure Share on → Copy SOCKS → set proxy on a second device → exit IP matches host tunnel.
