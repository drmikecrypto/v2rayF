# v2rayF v2.0.2

Live speed per protocol: honor Hysteria2 bandwidth and other sing-box throughput fields.

## Highlights

- **Hysteria2** — `up` / `down` Mbps from links and Clash applied as `up_mbps` / `down_mbps` (omit when unset)
- **TUIC** — `udp_relay_mode` when present; **WireGuard** — link/Clash `mtu`
- **Block IPv6** on sing-box rejects IPv6; Secure DNS UI notes first-page latency tradeoff

See [CHANGELOG.md](../CHANGELOG.md) and [latency-testing.md](../tips/latency-testing.md).
