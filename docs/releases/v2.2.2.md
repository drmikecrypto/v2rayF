# v2rayF v2.2.2

Android Instagram Direct (and other MQTT/raw-socket chat) works again on classic configs.

## Fixed

- Feed/reels could ride VPN HTTP proxy `10809` while **Direct** went dark on Xray gVisor TUN
- Android classic protocols back on **sing-box** TUN (`stack: system`, `file_descriptor`) — same class of path as V2Box
- v2.2.1 timeout safeguards kept (UDP DNS for Test delay; no ephemeral 10809 clash)

Desktop classic protocols stay on Xray. Hy2/TUIC/WG/anytls unchanged (sing-box).

## Install

Uninstall old APK → install 2.2.2 → Private DNS Off → Connect → **force-stop Instagram once** → open Direct.
