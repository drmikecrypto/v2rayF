# v2rayF v2.0.1

Smart Connect UX: connect the true fastest node; click-to-switch while already connected.

## Highlights

- **Smart Connect + Connect** tries the fastest working path first (selection / last-good no longer jump the queue)
- **While Connected**, selecting another config connects that server only (no Smart Connect re-rank override)
- Status: `Connecting to fastest…` then the chosen name
