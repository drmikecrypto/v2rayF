# v2rayF v1.4.1

Windows fix: TUN mode and kill switch can be used together without blackholing app traffic.

## Highlights

- Kill switch allows outbound on the `v2rayF` TUN adapter when TUN is enabled
- If that allow rule fails, kill switch is not armed and the status bar shows why (no silent offline Connected state)
- Docs: TUN + kill switch troubleshooting and Sentinel QA items
