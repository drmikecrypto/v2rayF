# v2rayF v2.0.5

Android WhatsApp: TUN apps get IPv4 DNS instead of AAAA into the IPv6 blackhole.

## Highlights

- VPN DNS is **172.19.0.1** (Xray `UseIPv4` when Block IPv6 is on)
- Port **53/853** → `dns-out` before `1.1.1.1`/`8.8.8.8` direct
- Chrome/Instagram still use HTTP proxy `127.0.0.1:10809`

Uninstall the old APK, install this one, reconnect, then force-stop WhatsApp once.

See [CHANGELOG.md](../CHANGELOG.md) and [tip-android-connect.md](../tip-android-connect.md).
