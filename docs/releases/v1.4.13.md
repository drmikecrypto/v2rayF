# v2rayF v1.4.13

Vision actually connects, Test All is faster and auto-sorts, live speed no longer cliffs from ping probes, settings sit behind one button.

## Highlights

- **Vision** — infers TLS/REALITY, 8s single-GET connect health, empty `pbk` refused, no Vision multipath
- **Test All** — parallel Xray workers, one `generate_204`, then **sort fastest first**
- **Live speed** — no 15s HTTPS ping loop; TUN MTU 1500; sniffing `routeOnly`
- **Settings** — one button (flyout / overlay), not a checkbox column
- **Xray links** — QUIC key, xHTTP extra, SS plugin-safe, VMess query-URI
